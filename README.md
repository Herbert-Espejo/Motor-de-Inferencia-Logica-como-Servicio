# Motor-de-Inferencia-Logica-como-Servicio
Proyecto de Programación asíncrona, programación lógica y funcional dentro de la materia Teoría de Lenguajes de Programación.

## Estructura

- `src/`: servidor Express y configuración del backend.
- `public/`: interfaz web estática (`index.html`, `css/`, `js/`).
- `data/`: base de conocimiento Prolog.
